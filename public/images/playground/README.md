# Playground Images

Place your images here for playground posts.

## Visual Posts

For visual posts (3D prints, design explorations, etc.), add images referenced in the frontmatter:

```yaml
type: "visual"
images:
  - "/images/playground/your-image.jpg"
```

## Recommended specs:
- 16:9 aspect ratio for best display
- 1600x900px or larger
- JPG or PNG format
- Optimized for web
